KEY FEATURES
================================================================================

Autonomous Monitoring:
  • 24/7 file system watcher via PM2
  • 5-second check interval (configurable)
  • Auto-restart on crash
  • Zero manual intervention required

Human-in-the-Loop Safety:
  • Company_Handbook.md defines approval thresholds
  • Auto-approve: known contacts, text files, small payments
  • Require approval: new contacts, payments ≥$50, executables
  • Escalation: 🚨 flag for urgent issues (auth failure, rate limit, etc.)

Structured Workflow:
  • Inbox: User drops files
  • Needs_Action: Watcher processes automatically
  • Pending_Approval: Claude requests user decision
  • Approved/Rejected: User routes action
  • Done: Completed tasks logged

Comprehensive Logging:
  • Text logs: human-readable, line-by-line records
  • JSON logs: structured events for analysis
  • Timestamps: ISO 8601 UTC format
  • Retention: 90 days minimum
  • Audit trail: traceable to action, actor, result

Extensibility:
  • BaseWatcher pattern: easy to add Gmail, WhatsApp, etc.
  • Agent Skills: reusable, testable, documented
  • MCP-ready: framework for Silver tier integration
